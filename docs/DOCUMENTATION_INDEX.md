2. Study [MODULE_CATALOG.md](MODULE_CATALOG.md) for patterns (30 min)
3. Reference [API_REFERENCE.md](API_REFERENCE.md) while coding (as needed)

### I Want to Contribute to the Project

1. Read [CONTRIBUTING.md](CONTRIBUTING.md) completely (40 min)
2. Review [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md) sections 1-3 (30 min)

5. Follow testing checklist from [CONTRIBUTING.md](CONTRIBUTING.md)
6. Submit PR with detailed description

**Total time:** 1-2 hours planning + development + testing

---

### I Need Help Troubleshooting

1. Check [FAQ.md](FAQ.md) - Troubleshooting section
2. Review [TESTING.md](../TESTING.md) - Error handling section
3. Check module-specific documentation in [MODULE_CATALOG.md](MODULE_CATALOG.md)
4. Review error logs: `/var/log/oziscript/`
5. Open GitHub issue if problem persists

**Resources:**
- System logs: `/var/log/oziscript/`
- Nginx logs: `/var/log/nginx/`
- Service status: `systemctl status {service}`
